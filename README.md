# Lista de Verificación de Calidad

## Proyecto

Open Hub Tec (Plataforma para conectividad limitada offline-first).

## Objetivo

Este repositorio contiene la lista de verificación, el sistema de insignias y la herramienta de auditoría automática utilizados para evaluar la calidad del proyecto.

## Documentos

* CHECKLIST-AUDITORIA.md
* SISTEMA-INSIGNIAS.md
* AUDITORIA-CMMI-MOPROSOFT.md
* RESULTADO-AUDITORIA.md
* scripts/AUDITAR-REPOSITORIO.ps1

## Auditoría automática

La herramienta de auditoría revisa elementos básicos de documentación, estructura, seguridad y control de versiones.

## Sistema de insignias

* 🥉 Bronce: 70% a 84%
* 🥈 Plata: 85% a 94%
* 🥇 Oro: 95% a 100%

La insignia definitiva se determina mediante una auditoría real del repositorio.
